ریسک ۴

تصمیم‌های نامزد

2. Decouple SAP using durable asynchronous processing.
3. Publish notifications asynchronously.
4. Validate expected load with representative performance tests.
5. Define EU deployment/data-storage rules explicitly.

نمونه ADR

Title:
Asynchronous SAP Integration

Driver:
Order acceptance >= 99.95%

Decision:
Persist accepted order and publish a durable integration event.

Consequences:
+ SAP outage no longer blocks acceptance
- eventual consistency
- duplicate handling required

سناریوی کیفی

Source:      SAP
Stimulus:    SAP unavailable for 30 minutes
Environment: Peak traffic
Artifact:    Order acceptance workflow
Response:    Orders continue to be durably accepted and queued
Measure:     Order acceptance availability >= 99.95%
             No accepted order is lost

Validation:
SAP outage simulation + queue durability test

قواعد انطباق

Payment vendor SDK may only be used in payment adapters.
Order Domain may not depend on infrastructure.
Order acceptance may not synchronously call SAP.
All integration events contain eventId, schemaVersion, timestamp.

آزمون کوتاه — ۱۰ پرسش

کدام گزینه بهترین توصیف محرک معماری است؟
پاسخ: نیازمندی یا محدودیتی که به‌طور مادی بر معماری اثر می‌گذارد — نه هر نیازمندی عملکردی، نه هر قرارداد کدنویسی، و نه فقط نیازمندی‌های کارایی.
کدام نما تعامل هنگام خطا در فرایند پرداخت را بهتر توضیح می‌دهد؟
پاسخ: نمای زمان اجرا. زمینه محیط را، بلوک ساختمانی ساختار ایستا را و استقرار زیرساخت را نشان می‌دهد.
کدام گزاره درباره ADR درست است؟
پاسخ: دلیل و پیامدهای تصمیم را ثبت می‌کند. جایگزین مستندات معماری نیست، برای هر انتخاب سطح کد لازم نیست، و می‌تواند جایگزین شود.
یک سرویس ۱۵ وابستگی خروجی دارد. چه نتیجه‌ای می‌گیرید؟
پاسخ: نشانه‌ای که نیازمند تحلیل زمینه‌ای است — نه اثبات معماری بد، نه الزام به تفکیک، و نه دلیلی برای صفر کردن وابستگی‌ها.
کدام مورد یک مفهوم فراگیر است؟
پاسخ: راهبرد سراسری مدیریت خطا. یک متد موجودیت، یک کوئری SQL یا یک قرارداد نام‌گذاری محلی‌اند.
کدام گزاره درباره بازخورد درست است؟
پاسخ: بازخورد می‌تواند فرض‌ها را پیش از پیاده‌سازی کامل اعتبارسنجی کند. فقط مخصوص محیط عملیات نیست، تکرار ریسک را حذف نمی‌کند، و بازخورد نیازمند اجماع نیست.
کدام مورد مستقیم‌ترین بررسی انطباق معماری است؟
پاسخ: تحلیل وابستگی‌های ممنوع.
هدف اصلی سناریوی کیفی چیست؟
پاسخ: ملموس و قابل تحلیل کردن یک کیفیت انتزاعی.
کدام گزاره درباره الگوهای معماری درست است؟
پاسخ: تناسب الگو به محرک‌ها و زمینه بستگی دارد. الگوها خودبه‌خود بهترین‌روش نیستند، مصالحه‌ها را حذف نمی‌کنند، و CPSA-F میکروسرویس را ترجیح نمی‌دهد.
قوی‌ترین رفتار Staff Engineer کدام است؟
پاسخ: ساخت حفاظ‌ها و توانمندسازی تیم‌ها برای تصمیم‌های سازگار — به‌جای تأیید شخصی هر تصمیم، تمرکز دانش یا جایگزینی مستندات با جلسه.

پرسش‌های مروری

چه چیزی یک نیازمندی را به محرک معماری تبدیل می‌کند؟

اثر مادی بر تصمیم‌ها یا ساختار معماری.

چرا فرض‌ها باید صریح باشند؟

فرض‌های پنهان ریسک مدیریت‌نشده می‌سازند.

چه چیزی یک تصمیم را از نظر معماری مهم می‌کند؟

تأثیر بالا، هزینه بازگشت، اثر بر کیفیت، پیامد بین‌تیمی یا محدودیت آینده.

انسجام در برابر کوپلینگ؟

انسجام یعنی میزان تعلق مسئولیت‌ها به هم؛ کوپلینگ یعنی وابستگی میان عناصر.

جعبه سیاه در برابر جعبه سفید؟

جعبه سیاه = مسئولیت و رابط‌های بیرونی؛ جعبه سفید = تجزیه درونی.

چرا معناشناسی رابط مهم است؟

نحو پایدار می‌تواند کوپلینگ معنایی را پنهان کند.

دغدغه در برابر مفهوم فراگیر؟

دغدغه = مسئله؛ مفهوم = راه‌حل معماری.

چرا مفاهیم فراگیر بر هم اثر می‌گذارند؟

هر مفهوم می‌تواند کیفیت یا محدودیت دیگری را تحت تأثیر قرار دهد.

چرا الگوها بهترین‌روش جهانی نیستند؟

وابسته به زمینه‌اند.

فایده حلقه‌های بازخورد کوتاه چیست؟

فرض‌های نادرست را زودتر آشکار می‌کنند.

چهار نمای اصلی کدام‌اند؟

زمینه، بلوک ساختمانی، زمان اجرا، استقرار.

نما در برابر نمادگذاری؟

نما = منظر؛ نمادگذاری = زبان.

تحلیل مبتنی بر سناریو چیست؟

ارزیابی معماری با استفاده از سناریوهای کیفی مشخص.

کیفی در برابر کمّی؟

قضاوت ساخت‌یافته در برابر شواهد عددی.

چرا معیارها به‌تنهایی کافی نیستند؟

معیارها به زمینه نیاز دارند و قابل دستکاری‌اند.

انطباق چه چیزی را ارزیابی می‌کند؟

اینکه آیا پیاده‌سازی با قصد معماری همسوست.

انحراف در برابر فرسایش؟

انحراف = فاصله گرفتن؛ فرسایش = تضعیف انباشته.

تابع تناسب چیست؟

ارزیابی عینی یک ویژگی معماری.
